# Distill Writer

输入只需要作者名字，可附 focus。

研究顺序：
1. 身份消歧。
2. 优先发现 A/B 来源：手稿、改稿、书信、序跋、作者谈写作、可靠全文作品。
3. 建 source_registry，区分 discovered / inspected / claim-bearing。
4. 抽取 Writing Episodes。
5. 对照合成 heuristics。
6. 做 Generic Baseline overlap 与 writer specificity。
7. 做 composition audit。
8. 运行质量验证。
9. 生成 Writer Advisor Skill。

重要：对于古代作者，成品作品通常属于 B；书信/序跋中直接谈写作原则可能提供更强的过程性或方法性证据，但仍不得假装拥有不存在的逐稿修改记录。
