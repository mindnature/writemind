# Personal Style Distiller

从用户自己的成稿、改稿和明确反馈中学习，不从一次样本或沉默推断稳定风格。

## 可用证据

优先级从高到低：
1. 用户明确说“保留/删掉/我喜欢/我不喜欢/以后都这样”。
2. 同一段 before → advisor → user final 的可观察修改。
3. 多篇已确认发表/满意的文章中的稳定模式。
4. 单篇文本统计，仅可做候选信号。

## Revision Episode

每次至少记录：
- context / platform / task
- original_text
- advisor_suggestion（如有）
- user_final_text
- accepted_changes
- rejected_changes
- user_feedback
- candidate_personal_rules
- writer_lenses_used

## 规则晋级

默认：
- 1 个独立 Revision Episode → `candidate`
- 2 个 → `provisional`
- 3 个及以上 → `validated`

只有明确用户反馈才能进入个人学习链。一次选择不得包装成“用户的稳定文风”。

## 四类 Personal DNA

- Voice：说话方式、距离、节奏、抽象/具体、习惯与禁忌。
- Structure：开头、段落推进、论证、案例、结尾。
- Revision：反复删/补/移/改的模式。
- Taste：为什么觉得一版好或不好。

## 冲突

用户当前明确要求永远优先。新反馈与旧 Profile 冲突时，记录新 Episode，并降低或重估旧 heuristic；不要为了保持画像一致而忽略用户当下要求。
