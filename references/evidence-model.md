# Evidence Model

## A — process evidence
作者写作当时或接近当时留下的手稿、修改痕迹、书信、写作笔记、编辑往来，能直接观察判断过程。

## B — authored text
作者正式作品。可以可靠观察“写了什么、怎么组织”，但从成品反推“为什么这样写”必须谨慎。

## C — retrospective author evidence
作者后来的创作谈、访谈、回忆。可用于理解自我解释，但存在事后合理化风险。

## D — third-party reconstruction
学术研究、传记、评论。适合补背景、形成候选解释，不应单独支撑强“作者内部算法”断言。

## Source ceiling

每位作者标记 source ceiling。古代作者即使作品极丰富，也可能缺失逐稿过程记录。系统应该降低微观心智推断，而不是补写一个漂亮故事。
